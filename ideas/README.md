# K-Health 경진대회 주제 후보

## 현재 후보 순위

| 순위 | 주제 | 성격 | 현재 판단 |
|---|---|---|---|
| 1 | 통증 멀티모달 정보 가치 분석 | 기술·성과 중심 | 결과물을 만들 가능성이 가장 높지만 경쟁 가능성도 높음 |
| 2 | 지역별 라이프로그 공통 건강영역 모델 | 데이터 활용 문제 중심 | 비교적 비전형적이며 미개방데이터 활용 취지와 잘 맞음 |
| 3 | 중증질환 개인 내 상대 프로파일 | 다영역 탐색 중심 | 독창적이지만 임상적 의미를 제한적으로 해석해야 함 |
| 4 | OMOP-CDM 심부전 진료경로 | 의료과정 분석 중심 | 실제 데이터의 규모와 추적 구조 확인 전에는 조건부 후보 |
| 5 | 심정지 환자 Vital Sign 상태전이 | 시계열 탐색 중심 | 분석은 가능하지만 대조군 부재로 활용 주장에 한계 |
| 6 | 안저 영상 장비·화각 일반화 | 의료영상 신뢰성 중심 | 주제는 좋지만 분야 지식과 영상처리 부담이 큼 |

## 공통 판단 원칙

- 설명서에 명시된 변수와 데이터 구조 안에서만 연구 질문을 설정한다.
- 표본 수, 환자 단위 연결 여부, 측정 시점, 결측 구조는 샘플 데이터 방문 후 확인한다.
- 관찰자료의 연관성을 인과관계로 표현하지 않는다.
- 질병 예측, 검사 절감, 위험군 선별 등은 이를 검증할 라벨과 비교군이 있을 때만 주장한다.
- 예선 평가 기준은 시의성 20점, 실현성 30점, 참신성 30점, 파급성 20점을 기준으로 검토한다.
