# 후보 2. 지역별 라이프로그 공통 건강영역 모델

## 한 줄 정의

지역마다 다른 장비와 검사 항목을 공통 건강영역으로 연결하고, 지역 간 비교가 가능한 최소 공통 변수 집합과 지역 고유 검사의 추가 정보량을 분석한다.

## 가제

**지역마다 다른 건강측정을 하나의 언어로: 이질적 라이프로그 데이터의 공통 건강영역 모델과 최소 검사 패널**

## 데이터 근거

광주 라이프로그 카탈로그에는 지역별로 서로 다른 검사 테이블과 항목이 제시되어 있다. 장비 모델과 컬럼 구조도 지역에 따라 다르며, 부분 측정, 장비 문제, 입력 또는 시스템 오류 등에 따른 결측과 이상치가 있을 수 있다고 설명되어 있다.

예시 건강영역은 다음과 같다.

- 혈압·심혈관
- 혈당
- 체성분
- 근력
- 자세·체형
- 족부 균형
- 보행
- 인지·뇌건강
- 폐활량
- 피부·시력 등

## 문제 정의

지역별 데이터가 같은 형식으로 수집되지 않으면 전체 데이터를 단순 결합할 수 없다. 이 프로젝트는 질병을 예측하기보다 **서로 다른 건강측정 데이터를 비교·결합할 수 있는 표현체계**를 만드는 데 초점을 둔다.

## 핵심 연구 질문

1. 지역별 검사 항목을 어떤 공통 건강영역으로 대응시킬 수 있는가?
2. 모든 지역에서 비교 가능한 최소 공통 변수 집합은 무엇인가?
3. 지역 고유 검사를 추가하면 개인 건강상태 표현력이 얼마나 증가하는가?
4. 일부 검사가 없는 사람도 공통 건강 프로파일로 표현할 수 있는가?

## 분석 단위

### 1단계: 변수 사전 구축

- 원본 변수명
- 측정 단위
- 방향성
- 측정 장비
- 소속 건강영역
- 지역 간 직접 비교 가능 여부
- 변환 또는 표준화 필요 여부

### 2단계: 공통 건강영역 표현

동일 측정치를 무리하게 합치지 않고 다음 수준을 구분한다.

- 완전히 동일한 정의와 단위를 가진 변수
- 의미는 유사하지만 장비나 단위가 다른 변수
- 동일 건강영역이지만 측정 개념이 다른 변수
- 특정 지역에서만 존재하는 변수

### 3단계: 최소 공통 패널 분석

- 공통 변수만 사용한 개인 프로파일
- 지역 고유 변수를 추가한 프로파일
- 변수 제거 전후의 정보 손실
- 결측이 있을 때 프로파일 안정성

## 가능한 방법

- 데이터 사전 및 온톨로지형 매핑
- 단위 통일과 지역 내 표준화
- 공통 변수 기반 차원축소
- 변수 집합별 설명분산 비교
- 결측 패턴 분석
- 지역 식별 가능성을 이용한 데이터 편향 진단

## 결과물

- 지역별 변수 대응표
- 공통 건강영역 스키마
- 최소 공통 검사 패널
- 추가 검사별 정보 증가량
- 지역 및 검사 가용성에 따른 데이터 품질 대시보드 또는 시각화

## 차별점

일반적인 건강위험 예측 대신 **파편화된 미개방데이터를 실제로 함께 사용할 수 있게 만드는 문제**를 연구 대상으로 삼는다. 모델 정확도 하나보다 데이터 호환성, 결측 대응, 비교 가능성을 결과물로 제시한다.

## 평가 기준과의 적합성

- 시의성: 지역·장비별 이질성을 다루는 데이터 표준화 문제
- 실현성: 질병 라벨 없이도 데이터 구조와 분포를 이용해 분석 가능
- 참신성: 데이터의 불일치와 파편화를 활용 주제로 전환
- 파급성: 향후 지역 데이터 통합과 후속 분석의 기반으로 사용 가능

## 주요 성립 조건

- 둘 이상의 지역에서 의미 있게 대응되는 공통 항목이 있어야 함
- 측정 단위와 변수 정의를 확인할 수 있어야 함
- 개인 식별자와 측정 시점 구조가 제공되어야 함
- 지역별 표본 수가 비교 가능한 수준이어야 함

## 피해야 할 주장

- 서로 다른 검사를 이름이 비슷하다는 이유만으로 같은 변수로 취급
- 표본 내 표준화 점수를 임상 정상·이상 판정으로 사용
- 결과 라벨 없이 “최소 질병선별 패널”이라고 표현
- 지역 차이를 주민 건강 차이로 즉시 해석
- 장비 효과와 지역 인구구성 효과를 구분하지 않고 설명

## 방문 시 확인사항

- 실제 제공 지역과 테이블 범위
- 지역 간 공통 변수의 정의·단위·장비
- 개인별 검사 교집합
- 동일인의 반복 측정 및 측정일
- 결측 코드와 비정상값 처리 규칙
- 연령·성별 등 기본 인구학 변수의 제공 여부

## 중단 또는 축소 기준

- 공통 변수가 매우 적으면 전체 광주가 아니라 2개 지역 또는 1개 건강영역으로 축소
- 단위와 정의 확인이 불가능하면 직접 통합 대신 “비교 가능성 진단”으로 범위 변경
- 개인별 검사 연결이 약하면 개인 프로파일 대신 변수·지역 수준 품질 분석으로 전환
